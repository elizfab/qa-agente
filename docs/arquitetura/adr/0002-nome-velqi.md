# 0002. Nome do produto: Velqi

- **Status:** Aceita (pendente de verificação de domínio e INPI)
- **Data:** 2026-10-10
- **Decisores:** Liza (Elizabete Fabri)

## Contexto

O nome de trabalho inicial era "Crivo", que já existe no mercado. Uma lista de candidatos foi pesquisada na web, no npm e em diretórios de software. Quase todos já estavam em uso, vários por produtos de IA ou de QA.

## Opções consideradas

| Nome | Conflito encontrado | Risco |
| --- | --- | --- |
| Crivo | Nome já existente | Alto |
| Qira | Assistente de IA da Lenovo/Motorola | Alto, mesmo ramo |
| Zelqa | Ferramenta de QA com LLM no GitHub | Alto, mesmo ramo |
| Aqira | Software de dados de teste (HBK) | Alto |
| Vexa | Vexa AI | Alto |
| Audra | Agente de IA auditor | Alto |
| Eviqa | Software de governança clínica (Reino Unido) | Médio |
| Veriq | Pacote `veriq` já publicado no npm | Médio |
| **Velqi** | Nenhum uso exato encontrado; apenas nomes próximos (velQip, Velqia) em outros ramos | Baixo |

## Decisão

O produto se chama **Velqi**: *Vel* (velar) + *q* (qualidade) + *i* (inteligência). Frase-guia: "A Velqi vela pela qualidade de cada entrega."

## Consequências

- O prefixo `velqi` é usado em código: `velqi-core`, `velqi-console`, `velqi-api`, `velqi_verify_plan`, CLI `velqi`.
- O nome `velqi` estava livre no npm na data da pesquisa.
- Pendente: verificar os domínios (`velqi.com`, `.ai`, `.dev`), consultar o INPI (classes 9 e 42) e pedir validação jurídica. Se houver bloqueio, esta ADR será substituída.
