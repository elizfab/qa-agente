# Protótipo do console

O protótipo é a referência visual do console antes do código Angular. As imagens desta pasta são geradas a partir do protótipo navegável (canvas de design). As versões em HTML estático ficam em [`prototipo/html`](prototipo/html) e podem ser abertas direto no navegador.
